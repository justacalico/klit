# 7.0.0

## Added

- Live responsive UI switching between mobile and desktop layouts
  - Pages now automatically switch between mobile and desktop views when resizing the window
  - Post detail, search, favorites, and profile pages all support live layout switching
  - Threshold: Desktop UI at ≥1024px width, Mobile UI below

- Shared navigation state between mobile and desktop UIs
  - When resizing from desktop to mobile (or vice versa), your current page is preserved
  - Example: If you're on Settings in desktop mode and resize to mobile, you stay on Settings
  - Navigation indices are automatically mapped between the different UI modes
  - Seamless experience when switching between layouts

## Changed

- Improved sidebar collapse button design
  - Added animated icon rotation when toggling collapse state
  - Shows "Collapse" label with chevron indicator in expanded mode
  - Added tooltip for better accessibility
  - Enhanced hover effects with purple gradient and shadow
  - Better visual consistency in both collapsed and expanded states

- New desktop time range selector for Hot and Popular pages
  - Modern glassmorphic design with purple/indigo gradient theme
  - Hover effects on time range options (Today, This Week, This Month)
  - Sleek calendar button with divider separator
  - Desktop-optimized date picker dialog with gradient styling
  - Enhanced "Done" button with purple gradient
  - Shows full date format (MMM d, yyyy) when custom date is selected
