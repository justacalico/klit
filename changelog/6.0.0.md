# 6.0.0

## Added
- Complete gamepad/controller support for desktop UI (SteamOS, Steam Deck compatible)
  - Full controller navigation for post detail view
  - Button mappings: LB/RB for post navigation, Y for favorites, RT for upvote, X for downvote, B to close, A for fullscreen
  - Thumbstick/D-pad navigation for sidebar menu
  - Visual button hints overlay when controller is connected
  - Haptic feedback for all controller actions
  - Login screen controller support with D-pad navigation between form fields and buttons
    - A button to select/activate focused item
    - Y button for quick guest login
    - X button to toggle custom host
    - Visual focus indicators on all interactive elements
- New input system with GamepadController service and GamepadInputMixin for easy integration
- Download functionality for desktop post detail view
  - Saves files to user's Downloads folder with progress indicator
  - Shows confirmation dialog with option to open folder
  - Detects if file already exists
- Live responsive UI switching between mobile and desktop layouts
  - Pages now automatically switch between mobile and desktop views when resizing the window
  - Post detail, search, favorites, and profile pages all support live layout switching
  - Threshold: Desktop UI at ≥1024px width, Mobile UI below

- Shared navigation state between mobile and desktop UIs
  - When resizing from desktop to mobile (or vice versa), your current page is preserved
  - Example: If you're on Settings in desktop mode and resize to mobile, you stay on Settings
  - Navigation indices are automatically mapped between the different UI modes
  - Seamless experience when switching between layouts

- Video settings section in both mobile and desktop settings
  - Auto Play: Control whether videos automatically play when viewing posts
  - Mute by Default: Start videos muted to avoid unexpected audio
  - Settings apply to both inline video player and fullscreen viewer
